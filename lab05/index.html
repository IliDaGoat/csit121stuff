Lab02 Reflection

Lab02 was all about learning the basic HTML structure. I learned more on how HTML functions, I learned general rules for tags should always be in lowercase, tags can be nested, and lastly tags can have attributes. I even learned HTML tags hold HTML elements, as well even learned opening tag starts a statement and closing tag closes any element. Lab02 also taught me head vs body, where the head is where it contains information about the page. And the body is everything we see in our websites. I learned how to structure my text by using headers, my paragraphs, break tags, unordered list, and ordered lists. Overall lab02 was learning the basics about HTMl

Lab03 Reflection

Lab03 was all about learn CSS style. CSS style is a language used to describe how to display that content. We use that language to change our text font, color, background color and so on. CSS saves a lot of work, it can control the layout of multiple web pages all at once external stylesheets are stored in CSS files. CSS defines styles for web pages, including the design, layout and variations in display for different devices and screen sizes. Easiest way to use css style is normally saved in an external .css file, which is easier than typing the design style for your code for everything page. Overall lab03 teaches us how to add designs to our webpage, make it more aliver and popout than just being plain old white.

Lab05 Reflection

Lab05 was an interesting lab, not only was it a bit difficult but it was an interesting module to learn. But it teaches us how to ensure webpages is user-friendly on both mobile and desktop devices. Teaches us how to use grid, float, and flex, it may sound complicated but once you start catching on you get the "Omg thats kinda easy" moment. I also learned that good web design should make a website easy to read, understand, and navigate. Using clear headings,readable font sizes, and consistent colors helps users find information more easily.
