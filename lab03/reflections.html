Lab03 Reflection

Lab03 was all about learn CSS style. CSS style is a language used to describe how to display that content. We use that language to change our text font, color, background color and so on. CSS saves a lot of work, it can control the layout of multiple web pages all at once external stylesheets are stored in CSS files. CSS defines styles for web pages, including the design, layout and variations in display for different devices and screen sizes. Easiest way to use css style is normally saved in an external .css file, which is easier than typing the design style for your code for everything page. Overall lab03 teaches us how to add designs to our webpage, make it more aliver and popout than just being plain old white.
